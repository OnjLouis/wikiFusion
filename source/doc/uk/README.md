# WikiFusion

WikiFusion — це додаток для NVDA, який об'єднує пошук у Вікіпедії та Вікісловнику в одному діалозі. Він містить інтелектуальну маршрутизацію, дерево результатів, функцію відтворення медіа та можливість використання полегшених джерел.

## Особливості

- Уніфікований пошук через Wikipedia та Вікісловник.
- Розумна маршрутизація:
  для окремих слів пріоритет надається Вікісловнику, для фраз — Wikipedia.
- Результати відображаються у вигляді дерева з:
  `Wikipedia`, `Вікісловника`, а також додатково `Uncyclopedia` та `Словника Urban`.
- Опціональне внутрішнє відтворення для вимови та інших аудіофайлів.
- Підтримка `ffmpeg` для декодування форматів, таких як OGG та OPUS, за наявності в `PATH`.
- Поведінка копіювання залежить від джерела:
  Wikipedia та Uncyclopedia копіюють заголовок і URL, Вікісловник та Словник Urban копіюють термін.

## Комбінації клавіш

- `NVDA+Alt+I`: відкрити WikiFusion
- `Enter` у полі пошуку: виконати пошук
- `Enter` на результаті: завантажити вибраний елемент
- `Ctrl+Enter` на результаті: відкрити вибраний елемент у браузері
- `Ctrl+C` на результаті: скопіювати текст із джерела
- `F1`: відкрити довідку щодо додатка.

## Медіа

- Панель медіа з’являється лише тоді, коли у поточному завантаженому результаті є медіафайли.
- `Enter`: запустити або зупинити відтворення вибраного медіафайлу
- `Пробіл`: призупинити або відновити відтворення
- `Ctrl+Enter`: завантажити вибраний медіафайл.

## Налаштування

- Код мови у Вікіпедії
- Код мови у Вікісловнику
- Включити результати з «Uncyclopedia»
- Включити результати з «Словника Urban»
- Максимальна кількість результатів
- Максимальна кількість визначень
- Увімкнути або вимкнути звук.

## Встановлення

1. Встановіть Wiki Fusion із [магазину додатків NVDA](https://addonstore.nvaccess.org/?addonId=wikiFusion&apiVersion=2026.1.0&channel=stable&language=en).
2. Перезапустіть NVDA, коли буде запропоновано.
